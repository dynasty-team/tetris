# Decision Log

| การตัดสินใจ | สิ่งที่เลือกใช้ | เหตุผล / Trade-off |
|---|---|---|
| Lock Delay | ใช้ Lock Delay 500 ms และรีเซ็ตได้สูงสุด 15 ครั้ง | เพื่อให้ผู้เล่นยังมีเวลาขยับหรือหมุนชิ้นส่วนหลังแตะพื้น ทำให้ควบคุมเกมได้ดีขึ้น แต่ต้องจำกัดจำนวน reset เพื่อป้องกันผู้เล่นถ่วงเวลาเกมไม่รู้จบ |
| 7-Bag Randomizer | ใช้ระบบ 7-Bag Randomizer แทนการสุ่มแบบสุ่มตรง ๆ | ทำให้ Tetromino ทั้ง 7 แบบกระจายสม่ำเสมอ ลดปัญหาชิ้นเดิมออกซ้ำมากเกินไปหรือบางชิ้นไม่ออกนาน และสามารถทดสอบได้ง่ายด้วยการเปลี่ยนฟังก์ชัน `shuffle` |
| Pause Handling | เมื่อ Pause ให้หยุด Gravity Tick แต่ยังคง Game State เดิม | ผู้เล่นสามารถพักเกมได้โดยตำแหน่งบล็อก คะแนน และสถานะเกมไม่เปลี่ยน เมื่อ Resume จึงสามารถเล่นต่อจากสถานะเดิมได้ |
| Save Timing | บันทึกข้อมูลเมื่อ Quit หรือ Game Over | ลดการเขียนไฟล์บ่อยเกินความจำเป็น และยังสามารถเก็บ High Score และสถิติของรอบล่าสุดได้เมื่อเกมจบ |
| Save Versioning | กำหนด `version` ให้ข้อมูล Save | เพื่อให้ระบบสามารถตรวจสอบความเข้ากันได้ของไฟล์ Save หากในอนาคตมีการเปลี่ยนโครงสร้างข้อมูล โดยปัจจุบันใช้ `version 1` |
