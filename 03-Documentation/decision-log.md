# Decision Log


| การตัดสินใจ | สิ่งที่เลือกใช้ | เหตุผล / Trade-off |
|---|---|---|
| Lock Delay | ใช้ Lock Delay 500 ms และรีเซ็ตได้สูงสุด 15 ครั้ง | เพื่อให้ผู้เล่นมีเวลาขยับหรือหมุนชิ้นส่วนหลังจากแตะพื้น ทำให้เล่นได้ลื่นขึ้นและควบคุมชิ้นส่วนได้ง่ายขึ้น แต่จะจำกัดจำนวนครั้งที่รีเซ็ตไว้ เพื่อไม่ให้ผู้เล่นยื้อเวลาได้นานเกินไป |
| 7-Bag Randomizer | ใช้ระบบ 7-Bag Randomizer | เลือกใช้เพราะช่วยให้ Tetromino ทั้ง 7 แบบออกกระจายมากขึ้น ไม่สุ่มซ้ำเดิมบ่อยเกินไป และไม่ทำให้บางชิ้นหายไปนานเกิน นอกจากนี้ยังทดสอบระบบสุ่มได้ง่ายขึ้นด้วย |
| Pause Handling | หยุด Gravity Tick ตอน Pause แต่เก็บสถานะเกมเดิมไว้ | เมื่อผู้เล่นกด Pause เกมจะหยุดการตกของชิ้นส่วนไว้ก่อน แต่คะแนน ตำแหน่งบล็อก และสถานะเกมจะยังเหมือนเดิม พอกด Resume ก็สามารถเล่นต่อจากจุดเดิมได้ |
| Save Timing | บันทึกเฉพาะ High Score ใหม่ตอน Quit หรือ Game Over | ไฟล์นี้เป็นสถิติถาวร ไม่ใช่ checkpoint ของรอบเกม จึงไม่เขียนสถานะการเล่นทุกครั้ง |
| Game Resume | ไม่รองรับการ resume เกมจาก SaveData | `CoreEngine` ยังไม่มี contract สำหรับ export/import สถานะ และการกู้คืนให้เล่นต่ออย่างถูกต้องต้องรวม board, active/next piece, score, level, line count และ bag randomizer; การบันทึกเพียงบางส่วนจะทำให้สถานะเกมคลาดเคลื่อน จึงกำหนด persistence ปัจจุบันเป็น high-score-only และตัด metadata ที่ไม่มี consumer ออก |
| Save Versioning | กำหนด `version` ให้ข้อมูล Save | ใส่ version ไว้เพื่อช่วยตรวจสอบว่าไฟล์ Save เป็นรูปแบบเดียวกับที่ระบบใช้อยู่หรือไม่ ถ้าในอนาคตมีการเปลี่ยนโครงสร้างข้อมูล จะจัดการไฟล์เก่าได้ง่ายขึ้น โดยตอนนี้ใช้ `version 1` |
| Top Boundary & Lock-Out | ตรวจขอบบนใน `checkCollision` (`y < 0`) และตั้ง Lock-Out Game Over เมื่อล็อก piece เหนือกระดาน | ตามข้อกำหนด Board: "Piece ต้องไม่สามารถเคลื่อนออกนอก board ได้" การตรวจจับขอบบนช่วยป้องกันไม่ให้ Wall Kick ดันชิ้นส่วนหลุดขึ้นเหนือแถว 0 ทำให้จำนวนบล็อกบนกระดานเพิ่มครบ 4 ช่องเสมอเมื่อล็อก และกำหนดพฤติกรรมชัดเจนว่าหากมี cell เหนือกระดานเมื่อล็อกจะถือเป็น Game Over (Lock-Out) ทันที |
| Board Dimension Validation | ตรวจสอบขนาดกระดาน 20 แถว × 10 คอลัมน์ (10 × 20 พอดี) ใน `TetrisEngine` constructor (`initialBoard`) และ `setBoard()` โดย throw Error ทันทีหากขนาดไม่ถูกต้อง | ป้องกันการรับ board ที่มีขนาดไม่ตรงกับมาตรฐาน 20 แถว × 10 คอลัมน์ ซึ่งอาจทำให้ `checkCollision` ตีความแถวที่หายไปเป็นช่องว่าง และ `lockPieceToBoard` ทิ้ง cell นอกขอบกระดานเงียบๆ ช่วยรักษาความถูกต้องและความสมบูรณ์ของ Game State |
