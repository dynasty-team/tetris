# Decision Log


| การตัดสินใจ | สิ่งที่เลือกใช้ | เหตุผล / Trade-off |
|---|---|---|
| Lock Delay | ใช้ Lock Delay 500 ms และรีเซ็ตได้สูงสุด 15 ครั้ง | เพื่อให้ผู้เล่นมีเวลาขยับหรือหมุนชิ้นส่วนหลังจากแตะพื้น ทำให้เล่นได้ลื่นขึ้นและควบคุมชิ้นส่วนได้ง่ายขึ้น แต่จะจำกัดจำนวนครั้งที่รีเซ็ตไว้ เพื่อไม่ให้ผู้เล่นยื้อเวลาได้นานเกินไป |
| 7-Bag Randomizer | ใช้ระบบ 7-Bag Randomizer | เลือกใช้เพราะช่วยให้ Tetromino ทั้ง 7 แบบออกกระจายมากขึ้น ไม่สุ่มซ้ำเดิมบ่อยเกินไป และไม่ทำให้บางชิ้นหายไปนานเกิน นอกจากนี้ยังทดสอบระบบสุ่มได้ง่ายขึ้นด้วย |
| Pause Handling | หยุด Gravity Tick ตอน Pause แต่เก็บสถานะเกมเดิมไว้ | เมื่อผู้เล่นกด Pause เกมจะหยุดการตกของชิ้นส่วนไว้ก่อน แต่คะแนน ตำแหน่งบล็อก และสถานะเกมจะยังเหมือนเดิม พอกด Resume ก็สามารถเล่นต่อจากจุดเดิมได้ |
| Save Timing | บันทึกข้อมูลตอน Quit หรือ Game Over | เลือกบันทึกตอนออกจากเกมหรือเกมจบ เพื่อไม่ให้ระบบเขียนไฟล์บ่อยเกินไป และยังเก็บ High Score กับข้อมูลของรอบล่าสุดไว้ได้ |
| Save Versioning | กำหนด `version` ให้ข้อมูล Save | ใส่ version ไว้เพื่อช่วยตรวจสอบว่าไฟล์ Save เป็นรูปแบบเดียวกับที่ระบบใช้อยู่หรือไม่ ถ้าในอนาคตมีการเปลี่ยนโครงสร้างข้อมูล จะจัดการไฟล์เก่าได้ง่ายขึ้น โดยตอนนี้ใช้ `version 1` |
